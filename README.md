# 微信群二维码

本仓库专门托管微信群的入群二维码图片，供主项目 README 引用，避免频繁改动主仓库。

![扫码进群](https://raw.githubusercontent.com/SII-ZhangYiFei/group-qr/main/group.png)

## 引用方式

在主项目 README 中加入下面这一行即可（只需加一次，之后无需再改）：

```markdown
![扫码进群](https://raw.githubusercontent.com/SII-ZhangYiFei/group-qr/main/group.png)
```

> 微信群二维码有效期为 7 天，`group.png` 由自动化流程每周更新。
